## What this guide covers

Stripe sends a webhook event to your server when something happens in your
account. A payment succeeds. A subscription renews. A customer disputes a
charge. Your server must receive the event, prove that Stripe sent it, and act
on it once.

This guide shows you how to do that in a small Node.js and Express server. You
test everything on your own computer with the Stripe CLI. You do not need a
public URL or a deployed server.

## Who this guide is for

This guide is for backend developers who:

- Use Stripe for payments, or plan to.
- Know basic JavaScript and Node.js.
- Want to confirm payments on the server, not only in the browser.

You do not need earlier experience with webhooks.

## What you will build

A webhook endpoint at `POST /webhook` that:

1. Accepts events only when the Stripe signature is valid.
2. Runs your code for the event types you care about.
3. Ignores an event that Stripe delivers a second time.
4. Responds quickly, so Stripe does not retry without need.

The complete example, with tests, is in the
[`examples/webhook-server`](https://github.com/myke-awoniran/stripe-webhooks-docs/tree/main/examples/webhook-server)
folder of this site's repository.
